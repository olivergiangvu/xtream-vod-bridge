## Incidents addressed

1. Non-root UID 10001 could not read two JavaScript files (0600); local Docker hotfix changed them to 0644. `Dockerfile.unified` now enforces this for future source builds.
2. First nginx cutover hit a transient 502 because an old worker was still connecting to retired 18768 during reload. Automated rollback passed; retry added reload grace and HTTP status retries; HTTPS cutover subsequently PASS.
3. Initial Unified catch-all passed unguarded root Admin routes to public 18450. Replaced with explicit `/a/` + `/play/` routing and protective nginx locations.
4. Compose ownership migrated to canonical `/opt/homedocker/stacks/xtream-vod-unified` and legacy containers were removed. Old SQLite checkpoints are historical: restoring them now discards all newer writes.
5. The later image-cleanup script exited before deletion (`STOP:ROLLBACK_ARCHIVE`) because its legacy bridge SHA constant had been truncated. Correct bridge image ID: `sha256:9483124a0c82c932dafcd42b2c5e36a77f8cc8b6d3ddbd475e6d20df0f0de367`.
